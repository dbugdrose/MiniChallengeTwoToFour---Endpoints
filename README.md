Endpoints:
1. endpoint that accepts 2 numbers, adds them together and prints out the results in a sentence.

2. endpoint that accepts 2 inputs in response to the following questions:
     - What is your name? 
     - What time did you wake up?

3. endpoint that accepts 2 numbers. Results print the following 2 statements:
     I. The first statement states whether the first number is greater than, less than or equal to the second number.
     II. The second statement states whether the second number is greater than, less than, or equal to the first number.
